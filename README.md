## 整合 MediaPipe 手部追蹤與 Unity 之體感互動系統

## 專案簡介

本專案為團隊畢業專題，主要實作整合 MediaPipe 手部追蹤與 Unity 的體感互動系統，並以第一人稱恐怖逃脫遊戲作為應用場景。

系統使用 Python 搭配 MediaPipe 進行即時手部追蹤與手勢辨識，取得手部關鍵點資訊後，透過手勢判斷與動態訊號處理，將辨識結果轉換為遊戲控制指令，再利用 UDP 傳送至 Unity，實現玩家移動、視角旋轉及遊戲互動。

開發過程中，針對動態手勢控制容易產生的辨識抖動、操作不穩定及誤觸問題，進一步加入平滑化、閾值判斷與冷卻時間等機制，改善體感操作的穩定性。

## 使用技術

- **程式語言：** Python、C#
- **手部追蹤與辨識：** MediaPipe
- **影像處理：** OpenCV
- **遊戲開發：** Unity 2022.3
- **網路通訊：** UDP
- **訊號處理：** 1€ Filter、EMA 平滑化、Dead Zone、Cooldown
- **版本控制：** Unity Version Control、GitHub

## 手勢辨識與控制系統

### 1. 手部追蹤與關鍵點分析

使用 MediaPipe Hand Landmarker 偵測手部關鍵點，取得手指與手掌的位置資訊，作為後續手勢判斷的依據。

透過關鍵點之間的距離、手指彎曲狀態及相對位置，建立靜態手勢辨識邏輯。

### 2. 靜態手勢辨識

根據手部關鍵點資訊判斷手指狀態及手勢特徵，辨識特定操作手勢，應用於遊戲中的物品拾取與互動。

### 3. 動態手勢辨識

針對玩家移動與視角控制需求，分析連續影格中的手部位置變化，將手部動作轉換為動態控制指令。

- 分析手部移動方向與位移。
- 利用連續影格判斷動態手勢。
- 將手部動作轉換為玩家移動及視角控制。

### 4. 訊號平滑化與穩定性改善

為改善手部追蹤過程中的座標抖動及操作不穩定問題，加入訊號處理機制：

- **1€ Filter：** 根據訊號變化速度動態調整平滑程度，在穩定性與反應速度之間取得平衡。
- **EMA 平滑化：** 降低連續影格之間的數值波動。
- **Threshold / Dead Zone：** 設定判斷閾值與操作死區，減少微小動作造成的誤觸。
- **Cooldown：** 設定觸發間隔，避免短時間內重複執行相同操作。

## Python 與 Unity 通訊整合

本專案將手勢辨識與遊戲控制分開處理，透過 UDP 建立 Python 與 Unity 之間的即時資料傳輸。

1. Python 使用 MediaPipe 取得手部關鍵點。
2. 執行手勢判斷與動態訊號處理。
3. 將辨識結果轉換為控制訊息。
4. 透過 UDP 將控制訊息傳送至 Unity。
5. Unity 接收訊息並執行對應的玩家控制與互動功能。

## Unity 遊戲應用

本系統以第一人稱恐怖逃脫遊戲作為實際應用場景，將手勢辨識結果整合至遊戲操作。

- **玩家移動：** 透過動態手勢控制玩家前進與移動方向。
- **視角控制：** 使用手部動作控制玩家視角旋轉。
- **物品互動：** 透過指定手勢進行物品拾取及機關互動。
- **遊戲機制：** 整合背包、道具、環境解謎、冷凍庫溫度限制及 Boss 追逐等功能。
